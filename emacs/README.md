# Emacs configuration

## External software

The following external software must be installed separately:

- cmark-gfm
- tsc
- emacs-lsp-booster https://github.com/blahgeek/emacs-lsp-booster
- pngpaste https://github.com/jcsalterego/pngpaste (macOS)
- alerter https://github.com/vjeantet/alerter (macOS)
- mbsync
- notmuch

In the source files, these are marked with comments of the form `;; EXTERNAL: `.
